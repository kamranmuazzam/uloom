# Biochemistry

Chemical basis of life, cellular metabolism, and molecular genetics:
- **Biomolecules**: Carbohydrates, lipids, proteins, and nucleic acids.
- **Metabolism & Bioenergetics**: Glycolysis, TCA cycle, oxidative phosphorylation, lipid oxidation, urea cycle.
- **Enzymology**: Enzyme kinetics, inhibition, coenzymes, and clinical enzymology.
- **Nutrition**:
  - `01Nutrition.typ`: Nutritional biochemistry, macro/micronutrients, and vitamin deficiencies.
- **Clinical Biochemistry**: Acid-base status, electrolyte balance, organ function tests (LFT, RFT, lipid profile).
- **Molecular Biology & Genetics**: DNA replication, transcription, translation, genetic disorders.
