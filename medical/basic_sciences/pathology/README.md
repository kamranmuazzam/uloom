# Pathology

Mechanisms of disease, cellular injury, and systemic pathology:
- **General Pathology**: Cell injury, cellular adaptations, inflammation, tissue repair, hemodynamic disorders, neoplasia.
- **Hematology**: Anemias, leukemias, lymphomas, bleeding disorders, transfusion medicine.
- **Chemical Pathology**: Laboratory evaluation of bodily fluids and biochemical markers.
- **Systemic Pathology**: Organ system diseases (CVS, respiratory, GI, hepatobiliary, renal, endocrine, musculoskeletal).
