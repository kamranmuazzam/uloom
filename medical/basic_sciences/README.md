# Basic Sciences (Pre-Clinical & Para-Clinical)

This directory contains foundational pre-clinical and para-clinical medical sciences:

- **[anatomy/](anatomy/)**: Gross anatomy, histology, osteology, embryology, neuroanatomy.
- **[physiology/](physiology/)**: Systemic human physiology, cellular physiology, biophysics.
- **[biochemistry/](biochemistry/)**: Clinical biochemistry, metabolism, molecular biology, genetics, nutrition.
- **[pathology/](pathology/)**: General pathology, systemic pathology, hematology, histopathology.
- **[pharmacology/](pharmacology/)**: General pharmacology, autonomic, cardiovascular, neuropharmacology, antimicrobials.
- **[microbiology/](microbiology/)**: Bacteriology, virology, mycology, parasitology, immunology.
- **[forensic_medicine/](forensic_medicine/)**: Legal medicine, medical jurisprudence, forensic pathology, toxicology.
- **[community_medicine/](community_medicine/)**: Public health, epidemiology, biostatistics, preventive medicine.
