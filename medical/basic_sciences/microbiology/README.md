# Microbiology

Pathogenic microorganisms and immune host responses:
- **General Bacteriology**: Bacterial structure, physiology, genetics, sterilization, and disinfection.
- **Systemic Bacteriology**: Gram-positive and Gram-negative pathogens.
- **Virology**: General viral structure, replication, DNA/RNA viruses, HIV, viral hepatitis.
- **Parasitology**: Protozoa, helminths (nematodes, cestodes, trematodes), vectors.
- **Mycology**: Superficial, subcutaneous, and systemic fungal infections.
- **Immunology**: Innate and adaptive immunity, hypersensitivity, autoimmunity, immunodeficiency.
